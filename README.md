# Sway for Claude Code

Sway checks how ChatGPT, Claude, Perplexity and Google's AI Overviews answer your buyers' questions: whether your brand is named, who is named instead, and which pages they cite. This plugin connects Claude Code to your Sway account, so you can work through your list of fixes from the terminal.

## Install

```
/plugin marketplace add shoustak/sway-claude-plugin
/plugin install getsway@sway
```

The first time a tool runs, Claude Code opens "Sign in with Sway" in your browser. You need a Sway account. It starts with a 7-day free trial, no card: https://getsway.ai

## Try

- "How often do ChatGPT, Claude and Google's AI answers name my brand, and who do they pick instead?"
- "Which rivals win the AI answers I lose, and which pages should I get mentioned on?"
- "Fix things in Sway: ship what you can and tell me what's left for me."

Sway changes your site only if you allow it in Sway's settings, and every change it makes keeps an undo.
